<h1 align="center">Orelia Extra</h1>
<p align="center">MMORPG Feature Plugin of Orelia-MC (archived)</p>

## アーカイブ済み

`orelia-extra` は [orelia-core](https://github.com/orelia-mc/orelia-core) に統合されました。Party・Friend・Guild・Chat・Trade・Mail・Auction・Housing・Pet・Mount・Ranking・Achievement を含む本リポジトリの全機能は、現在 orelia-core 1つのプラグインとして提供されています。

本リポジトリはアーカイブ済み(読み取り専用)です。以後の開発・Issue・PRはすべて [orelia-core](https://github.com/orelia-mc/orelia-core) で行われます。
